# Microsoft Teams Integration

Teams is optional.

Use the Teams connector for:
- High/Critical room issue notifications
- AV/facilities channel messages
- Adaptive Cards
- acknowledgement workflow if desired

Do not treat the Teams Power Platform connector as the room-usage telemetry source.

Teams Rooms Pro / Shared Spaces Insights remains a separate optional enrichment layer for the small subset of instrumented rooms.

Non-Teams rooms still participate in:
- dynamic inventory
- baseline availability
- sampled utilization
- feedback/issues
- Enhanced people demand if room event detail is approved
